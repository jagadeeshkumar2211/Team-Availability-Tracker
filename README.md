# Team Availability Tracker

A responsive team availability dashboard built with React, Vite, Express, and Node.js.

## Features

- View team member availability
- Update member status
- Add and remove team members
- Search and filter team members
- Automatic status refresh
- Responsive desktop and mobile interface

## Run locally

```bash
npm install
npm run dev
```

The frontend runs on Vite and the API runs on port `5000`.

## Production build

```bash
npm start
```

This builds the frontend and serves the application and API together.
